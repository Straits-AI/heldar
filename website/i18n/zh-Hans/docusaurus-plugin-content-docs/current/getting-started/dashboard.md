# 使用控制台

控制台是服务器与 API 一并托管的 React Web 界面（`apps/web`）——单一二进制文件，单一 URL（详见[部署](./deploy.md)）。本地与[远程](./remote-access.md)使用的是同一套界面；RBAC 控制每个角色可执行的操作。

## 登录

当 `HELDAR_AUTH_ENABLED=false`（局域网设备默认配置）时，控制台直接进入摄像头墙并拥有完整访问权限。启用认证后会显示**登录**界面（用户名 + 密码，可选 Cloudflare Turnstile 验证）；会话通过 HttpOnly Cookie 维持，登录后会出现退出控件。五种角色控制可见的功能——**admin**、**manager**、**guard**、**viewer**、**integration**——与服务端 RBAC 对应（证据锁定和配置变更需 manager 及以上权限，用户/Webhook 管理仅限 admin，viewer 为只读）。

顶部始终显示**遥测栏**：核心在线/离线状态、录制数量、摄像头/录像机/片段计数、存储占用、运行时长和时钟。

## 页面说明

**摄像头墙**（`/`）——多路摄像头实时网格及主页。支持自适应布局或固定布局（1×1 … 4×4），显示汇总统计（总数 / 录制中 / 离线 / 错误），可点击进入任意摄像头。

**摄像头详情**（`/cameras/:id`）——单路摄像头操作视图：低延迟**实时**视频（WebRTC/WHEP，HLS 备选）以及可点击拖拽的**录像时间轴**（1h / 6h / 24h / 3d）。在此可截取快照、导出证据片段（MP4）、锁定证据片段、触发手动录制（事件模式），并管理摄像头的 **AI 任务**和**区域**（见下文）。面板显示最近片段和事件、健康遥测（FPS、码率、重连次数）、PTZ、录制计划以及 ANR 断录补录。

**回放**（`/playback`）——多路摄像头同步回顾：选择摄像头和时间窗口，通过共享的播放/暂停/跳转和速度控制（0.5× … 4×）在同一主时钟上同步拖拽。

**添加摄像头**（`/cameras/new`）——注册摄像头。选择厂商（Hikvision / Dahua / 通用）；RTSP URL 从厂商模板构建（填写地址 + 凭据）或对通用类型直接指定。设置录制模式（连续 / 定时 / 事件 / 定时+事件）、码流、片段时长、保留策略、单摄像头存储配额，以及事件模式的前/后缓冲时长。

**发现**（`/discover`）——扫描 IP 范围以查找 RTSP 摄像头（及 ONVIF），从 Banner 识别厂商/型号，验证凭据，并跳转到预填信息的添加摄像头页面（需 manager 及以上权限）。

**AI**（`/ai`）——感知控制台：只读查看各摄像头帧**采样器**状态（状态 + 有效 FPS）及已启用的 **AI 任务**，以及共享 FPS 预算/背压模型。任务的创建和调整在摄像头详情页完成。

**事件**（`/incidents`）——证据案例管理：以自由格式事件 ID 分组的片段，支持播放、证据锁定/解锁以及重新归类到其他案例（需 manager 及以上权限）。证据锁定的录像不会被保留策略清除。

**备份**（`/backup`）——备份**目标**（本地 / SFTP / FTP / S3）和**策略**（摄像头 × 目标 × 间隔），包含状态的任务台账，以及按需**归档导出**（选择摄像头 + 日期范围，下载 `.zip`）。

**插件**（`/plugins`）——插件商店：浏览合并后的注册表（内置 + 远程），安装或卸载模块和 Sidecar（需 manager 及以上权限），查看已验证/已签名标识及各插件的 Webhook 凭据。

**系统**（`/system`）——健康与可观测性：存储面板（磁盘占用、预计存满时间、写入速率）、**录制限制**控制（容量上限 + 剩余磁盘下限，可实时调节——需 admin 及以上权限）、各摄像头健康状态、最近事件流、不可变**审计日志**（需 manager 及以上权限）、批量摄像头配置，以及 Webhook 面板（需 admin 及以上权限）。

## 领域模块

除平台页面外，控制台还根据运行二进制文件所组合的应用渲染**模块**部分（`GET /api/v1/modules`）——导航自动更新，无需重新构建。开源通用应用包括：

- **Entry** — 访问控制台（车牌授权、访客/车辆/黑名单注册、保安确认/拒绝工作流、报告）。
- **Movement** — 跨摄像头移动智能（人工审核的 ReID 候选、禁区闯入事件）。
- **Search** — 对存储事件数据的自然语言查询，每条答案附有证据链。

各模块在[运维](../operate/index.md)中心提供操作指南。Sidecar 插件以沙箱 iframe 形式挂载在 `/m/{id}/` 下（详见 [Sidecar 插件](../develop/sidecar-plugins.md)）。

## 区域与 AI 任务

在摄像头详情页：

- **AI 任务** — 创建单摄像头检测任务（`task_type`、请求的 `fps`、采样 `width`，以及工作进程读取的自由格式 `config`）。启用第一个任务会启动该摄像头的帧采样器；参考 [AI 工作进程](../develop/ai-worker.md) 拉取帧并回传检测结果。
- **区域** — 绘制多边形区域（归一化 0..1，与检测框对应），设置计入的 `labels`、`dwell_seconds` 阈值和 `severity`。被追踪的检测目标穿越区域时触发 `enter` / `exit` / `dwell` 事件并附带证据帧，用于驱动告警。
