# Heldar reference AI worker — FULL local install (core + the optional model stack).
#
# Core runtime (always required) — intentionally light: HTTP + frame decode. It lives in
# requirements-core.txt so the container image (apps/ai/Dockerfile) can install ONLY the core and
# stay small + multi-arch buildable (torch/opencv are ~2 GB per architecture — enough to overflow a
# CI runner's disk); worker.py imports the model stack lazily, so the core-only image runs every
# motion-type task and cleanly reports model-type tasks as unavailable.
-r requirements-core.txt

# which are large (~2 GB) and download on first install. It is only imported
# lazily when a YOLO task actually runs, so motion-only deployments can omit it.
# GPU is used automatically when torch detects CUDA; otherwise it runs on CPU.
